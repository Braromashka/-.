Весь код проекта, включаю визуализацию расположен в файле "Сегментация клиентской базы выявление доминирующих кластеров пользователей методами многомерного анализа.ipynb" (можно открыть в удобной среде разработки). За основу анализа был взят файл (dataset_telecom.csv), который содержит реальные данные по клиентам телекоммуникационнной компании.

Решение прикладной бизнес-задачи,которое включает в себя этапы: сбора данных, их предварительной обработки, исследовательского анализа, визуализации данных, проверку соответствующей гипотезы. 
Цель проекта: Сегментация клиентской базы: выявление доминирующих кластеров пользователей методами многомерного анализа.

Проект выполнен по следующим критериям:
- выполнена загрузка и чтение данных из файлов (см. файл dataset_telecom.csv);
- выполнена предварительная обработка данных;
- применены методы математической статистики для обработки данных;
- выполнен поиск закономерностей в данных;
- сформулированы и проверены гипотезы;
- выполнена визуализация данных;
- полученные результаты интерпретированы в соответствии с поставленной бизнес-задачей
